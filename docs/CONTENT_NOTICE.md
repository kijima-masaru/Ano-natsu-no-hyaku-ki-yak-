# コンテンツ警告と相談窓口案内の方針

本作は「人を自死に至らせる怪異」を扉として、残された者の取り返しのつかなさを描く。
以下は開発中に守る描写制約と、リリース時に組み込む警告・案内の方針を定める。

## 1. 描写制約（開発中、全テキスト・全演出に適用）

| 禁止 | 代替 |
|---|---|
| 自死の方法・手段（器具・場所・手順・状態）を具体的にも暗示的にも描く | 「そうなってしまった」「もういない」。事後の生活の痕跡（靴、夕飯の匂い、乾かない洗濯物、未返信）と周囲の反応だけで伝える |
| 死の場面そのものを描く | 常に事後。発見現場も「場所」としてしか描かず、時間を飛ばす |
| 怪異が人を死に至らせる過程を手順・方法として描く | 「連れて行かれた」「帰ってこなかった」という結果と噂話のみ |
| 自死を救済・解放・美化として描く | 残された者の側から描く。蓮の母、トキ、澪の視点を必ず置く |
| 主人公の「捧げる」行為を手順として描く | 「頷いた」「先に帰った」の間を空白にする。真相版でも空白を埋めない |
| 終幕で澪が悠を討つ場面の方法・状態 | 「町の外へ出さない」「告発する」。翌朝の事後（橋のバリケード、揃えられた靴）のみ |

- テキストレビュー：`messages.json` の全エントリを PR ごとに上表で確認する。疑わしい表現は削る側に倒す。
- 語彙の禁止リスト：具体的な手段を示す名詞・動詞は `docs/` に列挙せず、レビュー時に個別判断する（列挙自体が手段の記述になるため）。
- 「見せないことが最も怖い」を演出の基準にする。空白・無音・不在で作る。

## 2. リリース時の警告表示（タスク2 タイトル画面で枠だけ実装、文言はステップ5）

1. **初回起動時**、タイトルの前に全画面でコンテンツ警告を表示する。スキップ不可、既読で `user://system.json` に記録。
2. 内容：「本作には、自死とその喪失を扱う描写、追跡される恐怖、心理的な操作の描写が含まれます。具体的な方法は描写しません」の趣旨。
3. **設定画面**から再表示できる。
4. **相談窓口案内**：警告画面と設定画面に「つらいときは、話せる場所があります」として、配信地域ごとの公的相談窓口を表示する。連絡先はローカライズデータ（`data/locale/<lang>/support.json`）として配信地域確定後に差し込む。本リポジトリでは **プレースホルダ** とし、実在の団体名・番号は書かない。
5. Steam ストアページの「成人向けコンテンツの説明」欄にも同趣旨を記載する（ステップ5）。

## 3. ゲーム内の運用

- 8/30 夜の隠蔽リスト提示と 8/31 のエンディングの直前に、短い暗転と無音を置き、プレイヤーが一呼吸できるようにする。
- エンディング後、スタッフロールの前に相談窓口案内を再度表示する。
- 「裏面」モード（周回）でも警告は省略しない。

## 4. 実装への反映箇所

| 項目 | 実装タスク |
|---|---|
| 初回警告画面・設定からの再表示 | feat/save-system（タイトル）/ feat/dialogue-system（設定） |
| `user://system.json` への既読記録 | feat/save-system |
| ローカライズ差し込みの枠 | feat/dialogue-system（`messages.json` の隣に `support.json` の読み込み口） |
| エンディング前後の案内 | ステップ4 |
