# 欺瞞対応表（DECEPTION MAP）

主人公・篝悠がプレイヤーに嘘をつく箇所の全一覧。
すべて `data/messages.json` の `id`（表層版）と `truth_id`（真相版）の対で管理し、**`MessageResolver.resolve(id)` の 1 関数だけ**が `truth_revealed` を見て切り替える。
切替フラグは特記なき限り `truth_revealed`。表層版を表示した時点で `seen_<id>` が立ち、真相到達時の「あなたが読んだ嘘」一覧に使う。

原則：真相版でも **方法・状態・過程は書かない**。空白を空白のまま残す。

## 集計と実装要件

- 対象 ID：A 5、B 5、C 6、D 12、E 5、F 4 ＝ **37 対**。ステップ3の実装範囲（8/1〜8/4、F01/F02/F05/F06/F12）で実装するのは A-a〜c、B-door/smell/laundry、C-storefront/shoes、D-001〜004、E-001、F-vending/home の **16 対**。
- `messages.json` の各エントリは `{ "id", "speaker", "text", "truth_id" }`。`truth_id` を持つエントリは `MessageResolver` が `truth_revealed` を見て差し替える。
- **検証**：起動時に `truth_id` の参照先が存在することを全件チェックし、欠落は push_error。
- デバッグオーバーレイで `truth_revealed` を切り替え、全 37 対が差し替わることをプレイテスト（タスク15）で確認する。
