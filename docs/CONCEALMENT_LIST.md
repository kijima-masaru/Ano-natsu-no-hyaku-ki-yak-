# 隠蔽リスト（CONCEALMENT LIST）

主人公・篝悠が調査中に「密かに処分する」証拠の全一覧。
プレイヤーは該当オブジェクトを **調べる** だけで、画面には「特に何もなかった」等の表示しか出ない。
内部では `conceal_evidence` アクションが走り、`GameState.concealed_evidence` に記録される。
8/30 夜の真相到達時、この一覧が「実際に悠がしたこと」とともに提示される。**本作最大の一撃。**

## 隠蔽の判定（`feat/evidence-and-suspicion` / `feat/companion-heroine`）

1. `conceal_evidence` 実行時、澪が `companion_on` かつ悠から `HEROINE_WITNESS_RADIUS`（4 タイル＝64px）以内にいれば **失敗**。
2. 失敗時：証拠はノートに載る（澪が拾う）。`hid_fail_<id>` が立ち、接近度 +20。プレイヤーには「澪が先に手を伸ばした」とだけ表示される。
3. 成功時：`hid_<id>` が立ち、ノートには載らない。表示は下表の「プレイヤーへの表示文」。
4. 成功・失敗ともプレイヤーに数値は見せない。

## 提示画面（8/30 夜）の構成

1. 黒地に「あなたが調べたもの」。プレイヤーが見た表示文が、調べた順に 1 行ずつ出る。
2. 各行の下に、行間を空けて「実際にしたこと」が真相版の文字色で重なる。
3. 失敗した隠蔽は「澪が先に手を伸ばした」の行の下に「澪はそれを、ずっと持っていた」。
4. 最後に空行を置き、ナツの `msg_natsu_009`（真相版）。
5. 文字送りはこの画面だけスキップ不可。ページ送りは可。
