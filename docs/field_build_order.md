# 磐戸町奇譚 ── フィールド作成の推奨順序（成果物C）

対象：`data/fields.json` の16フィールドを `.tscn`（TileMapLayer 構成）化していく順序。
判断軸は **①ストーリー導線（早く遊べる範囲から）／②技術的な依存関係（ハブ・鍵・マップ解放）／③タイルセットの再利用効率（同じタイル群を続けて使い切る）** の3点。

**節目**
- 1〜5 で「序盤の環状ルート」が完成し、通しプレイ可能になる（ここでプレイ感を評価する）。
- 6〜10 で中央〜南部が埋まり、中核ダンジョン F11 を中心に中盤が閉じる。
- 11〜16 で「裏側」（F03 隧道の先）と終盤を作る。固有タイル比率が高い F09・F16 を最後に置く。

## 技術メモ（次ステップへの引き継ぎ）
- 1フィールド = 1 `.tscn`。`TileMapLayer` を「地面／建物・壁／装飾／光源（加算合成）／衝突」の5層で統一する。
- 共通タイルセットは `res://tilesets/common.tres` に1枚、固有分は `res://tilesets/fXX_extra.tres` に分ける。フィールドシーンは両方を参照する。
- 暫定素材は `Image`/`ImageTexture` によるプロシージャル生成 GDScript で作る（パレットは `fields.json` の `meta.palette` を読む）。
- 出入口は `exits[].tile` の位置に `Area2D` を置き、`lock` が非 null のものは `meta.locks` のフラグを `GameState` で判定する（ステップ2以降）。
